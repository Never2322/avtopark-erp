# Автопарк — учёт техники, ремонтов и путевых листов

Новая программа для спецтехники: React + TypeScript (сайт), Python FastAPI (сервер, описание интерфейса со Swagger на `/api/docs`), PostgreSQL. Всё запускается в Docker одной командой.
Старая программа на Flask (`replica-clone`) не тронута и работает как раньше. Перенос данных из неё будет отдельным скриптом.

Что входит в первую очередь: вход и роли, юридические лица, сотрудники и пользователи, реестр техники и карточка, история пробега и моточасов, статусы и закреплённые водители, обращения и ремонты, путевые листы, журнал действий, резервные копии. Дополнительно перенесены из старой программы: личные дела водителей и техники (фото, паспорт, права, СТС, ПТС), справочники (контрагенты, тарифы, константы) и деньги (топливные карты, штрафы, аренда, расходы, выплаты, счета и касса); что ещё не перенесено: [docs/Перенос-из-старой-программы.md](docs/Перенос-из-старой-программы.md). Подробно, что сделано и что нет: [docs/Что-готово-и-что-нет.md](docs/Что-готово-и-что-нет.md).

## Самый простой способ (Windows)

1. Один раз поставьте Docker Desktop (если его нет, `Запустить.bat` сам откроет страницу загрузки).
2. Дважды щёлкните **`Запустить.bat`**. Он сам придумает пароли, создаст файл `.env`, соберёт и запустит программу (в первый раз несколько минут), покажет логин и пароль для входа и откроется сайт.
3. Выключить: **`Остановить.bat`**. Данные и копии при этом сохраняются. Снова включить: `Запустить.bat`.

Эти два файла написаны, но на настоящем Windows ещё не пробовались. Если что-то пойдёт не так, ниже тот же запуск вручную.

Если нужно начать с нуля (стереть базу и пароли): `docker compose down -v`, удалить файл `.env` и снова запустить `Запустить.bat`. Без `-v` база помнит старый пароль, и новый не подойдёт.

## Как запустить вручную (на компьютере или сервере)

1. Установите Docker (на Windows и Mac — Docker Desktop, на Linux — Docker Engine с плагином Compose).
2. В папке проекта скопируйте `.env.example` в `.env` и откройте его в блокноте:
   - `POSTGRES_PASSWORD` — любой длинный пароль (его вводить больше нигде не придётся);
   - `ADMIN_LOGIN` и `ADMIN_PASSWORD` — ваш вход в программу (пароль не короче 8 символов, не «12345678»).
3. Запустите: `docker compose up -d --build`. Первая сборка занимает несколько минут.
4. Откройте http://localhost:8080 (порт меняется строкой `HTTP_PORT` в `.env`) и войдите под `ADMIN_LOGIN`.
5. Дальше всё делается в самой программе: «Юридические лица» → «Сотрудники» → «Пользователи» (каждому дайте роль; водителю привяжите его карточку сотрудника) → «Транспорт».

Первый администратор создаётся один раз, пока в базе нет ни одного пользователя. После первого входа смените пароль в «Профиле», а строки `ADMIN_*` из `.env` можно удалить.

Посмотреть демо-данные (вымышленные) можно командой `docker compose exec backend python -m app.cli seed-demo --yes` (после создания администратора и пока в базе нет техники). Она создаст четырёх демо-пользователей и один раз выведет их пароли; при первом входе система попросит пароль сменить. На рабочей базе её не запускайте.

## Копии базы

- Раз в сутки в 03:00 (время организации) программа сама делает копию. Хранится `BACKUP_KEEP` последних копий (по умолчанию 14) и последняя проверенная.
- Кнопка **«Проверить»** в разделе «Резервные копии» разворачивает копию во временную базу, сверяет число строк в каждой таблице и версию схемы, потом временную базу удаляет. Копия, которую ни разу не проверили, ничего не гарантирует.
- Файлы лежат в томе Docker `backups` на том же сервере. **Если сервер сломается целиком, копии пропадут вместе с ним**, поэтому периодически скачивайте копию кнопкой «Скачать» и храните в другом месте.
- Восстановление: `./scripts/restore.sh путь/к/копии.dump`. Скрипт спросит подтверждение (нужно ввести ДА), остановит программу, заменит базу и запустит снова. Всё, что вводили после времени копии, придётся ввести заново.

## Свой домен и https

1. В `.env` добавьте `DOMAIN=ваш.домен` и поставьте `COOKIE_SECURE=true`.
2. Направьте домен на адрес сервера и откройте порты 80 и 443.
3. Запустите `docker compose --profile https up -d`. Сертификат Caddy получит и будет продлевать сам.

После этого порт `HTTP_PORT` лучше закрыть на файрволе. Страницу `/api/docs` на рабочем сервере выключите: `DOCS_ENABLED=false`.

## Программа на телефоне водителя

Сайт открывается в браузере телефона. Чтобы он стал похож на приложение (значок, запуск без адресной строки) и **открывался без связи**:

1. Нужен адрес с `https://` (см. выше). По обычному `http://192.168…` служебный скрипт браузера не включается: сайт работает, но без сохранения в телефоне.
2. Водитель открывает сайт один раз при связи и входит под своим логином.
3. Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран». iPhone (Safari): кнопка «Поделиться» → «На экран “Домой”».
4. Без связи записи (рейс, заправка, «Приехал», «Закончил», фото к наряду) сохраняются в телефоне и уходят сами, когда связь появится. Список неотправленного виден на главной водителя и на странице «Ждут отправки».

Если на телефоне работают двое, при выходе из программы сохранённое от первого стирается. Не выходите из программы, пока в списке есть неотправленные записи: очередь привязана к человеку.

## Обновление

`git pull` (или замените файлы), затем `docker compose up -d --build`. Схема базы обновляется сама при старте. Перед обновлением сделайте копию.

## Как устроено

- `backend/` — сервер: `app/routers` (интерфейс), `app/models.py`, `alembic/` (миграции), `app/permissions.py` (права и роли по умолчанию), `app/services` (копии, показания, нумерация, файлы), `tests/`.
- `frontend/` — сайт: `src/pages` (экраны), `src/ui.tsx` (общие элементы), `src/styles.css` (тёмная тема из пакета проектирования).
- `docker-compose.yml`, `Caddyfile`, `scripts/restore.sh`, `.env.example`, `Запустить.bat`, `Остановить.bat` и `scripts/*.ps1` (помощники для Windows).
- Подробности для разработчика: [docs/Разработка.md](docs/Разработка.md). Роли и права: [docs/Роли-и-права.md](docs/Роли-и-права.md) (таблица пересобирается командой `PYTHONPATH=backend python3 scripts/role_matrix.py`, когда меняется `permissions.py`).

## Безопасность коротко

Пароли хранятся только в защищённом виде (argon2). После 5 неудачных попыток входа подряд вход для этого логина блокируется на 10 минут. Сеансы хранятся на сервере и закрываются кнопкой «Выйти» и при отключении пользователя. Чужие данные выглядят как «не найдено». Показания, журнал действий, история статусов и загруженные сканы защищены от изменения и удаления самой базой, а не только программой. Паспорта видны только тем, у кого есть отдельное право, и каждый просмотр скана пишется в журнал.
