# Перенос из старой программы

Старая программа (`replica-clone`, SQLite) продолжает работать и не тронута. Новая переносит разделы по очереди; данные из старой базы переносятся отдельным скриптом после того, как разделы будут готовы.

| Раздел старой программы | В новой | Примечание |
|---|---|---|
| Транспорт, показания, статусы | готово (очередь 1) | |
| Обращения и ремонты (заявки) | готово (очередь 1) | |
| Путевые листы | готово (очередь 1) | |
| Сотрудники, пользователи, роли | готово (очередь 1) | добавлены юрлица |
| Личные дела водителей и техники | **готово, новое** | фото, паспорт, права, СТС, ПТС и др.; в старой не было |
| Контрагенты, тарифы, константы | готово | общие для юрлиц |
| Топливные карты | готово | заправки внесены отдельным разделом; привязка заправки к карте и сверка с выпиской позже |
| Штрафы | готово | напоминания и «водителю сообщили» позже |
| Аренда техники | готово | |
| Прочие расходы, выплаты сотрудникам | готово | |
| Счета, касса и банк | готово | печатные формы ПКО/РКО есть (упрощённые) |
| Заказы и документы (счета, акты, ТН, УПД) | **готово** (этап 2а) | расчёт по тарифу, нумерация, печатные формы; отчёт «Заказы по заказчикам» и выгрузка в Excel-файл позже, пока есть CSV |
| Наряды на день | **готово** (этап 2б-1) | доска дня, отметки водителя, фото до и после, повтор на завтра; работа без связи готова (2б-3); уведомления водителю позже |
| «Записи водителей» (рейсы, заправки) | **готово** (этап 2б-2) | внесение с телефона с фото накладной и чека, расход на 100 км, объём бака и норма на карточке техники, лента для диспетчера; работа без связи готова (2б-3) |
| Кабинет водителя (телефон, PWA) | **готово** (этап 2б-3) | главная водителя, установка на главный экран, очередь отправки без связи; нужен https:// для сохранения программы в телефоне |
| «Водители и техника» (сводка) | **готово** (этап 2б-3) | кто на чём, состояние, наряд, заправка, замечания, выгрузка CSV |
| Детали в обращениях, «Что купить», каталог запчастей | **готово** (этап 2в) | подсказки из каталога, «уже меняли», статус двигается от покупки; уведомления позже (этап 3) |
| Счета на ремонт | **готово** (этап 2в) | выписать в программе или внести счёт поставщика, чтение PDF с текстом, оплата, итоги и сводка; фото и сканы читаются вручную (этап 4) |
| Табель | **готово** (этап 3а) | сетка месяца, коды как в старой программе (Я, Н, РВ, С, К, ОТ, ОД, ДО, Р, ОЖ, Б, Т, ПР, НН, РП, В), заполнение, печать, CSV; праздничные дни не учитываются |
| СИЗ (нормы и выдача) | **готово** (этап 3а) | нормы, выдача, срок замены считается сам, замена в один клик, блок в карточке сотрудника; напоминание о сроке замены есть в напоминаниях и календаре (3б) |
| События сотрудников, календарь, напоминания | **готово** (этап 3б) | медосмотры, права, инструктажи, нарушения, ДТП, премии и штрафы со сроками; календарь (месяц, неделя, день, год) со сроками из разделов и своими событиями; страница напоминаний; уведомления, Telegram и почта позже (3в, этап 4) |
| Объявления, уведомления | **нет** | этап 3 |
| Склад (остатки, движения) | **нет** | этап 4 |
| Отчёты, выгрузка в Excel, печатные формы | **нет** (есть выгрузка CSV у новых разделов) | этап 4 |
| Импорт пробега, GPS | **нет** | этап 4 |
| Telegram и почта, веб-пуш, распознавание документов | **нет** | этап 4 |
| Копия вне сервера | **нет** | этап 4 |
| Вкладки карточки техники: шины, история ремонтов, финансы по технике | **нет** | после этапа 2 |
| Перенос данных из старой базы | **нет** | отдельный скрипт, после согласования соответствия справочников |

Отличия по устройству: в старой программе нет юридических лиц, в новой каждая запись принадлежит юрлицу, а права выдаются по юрлицам. Суммы в старой хранятся в копейках целым числом, в новой в `Numeric(14,2)` (рубли с копейками); скрипт переноса это учтёт.
